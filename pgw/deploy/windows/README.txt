PGW — Protocol Gateway. Как запустить (Windows)
====================================================================

Этот exe требует установленный .NET 8 (Runtime или SDK). Если его нет —
поставь: https://dotnet.microsoft.com/download/dotnet/8.0 (раздел
"ASP.NET Core Runtime 8.0.x", колонка Windows x64 Installer — этот
установщик легче полного SDK).

САМЫЙ ПРОСТОЙ СПОСОБ (увидеть, как всё работает, с тестовыми данными)
----------------------------------------------------------------------
1. Двойной клик на run-simulate.bat — откроется окно, оно поднимет
   тестовые Modbus TCP и OPC UA серверы с "дышащими" значениями.
   ОСТАВЬ ЭТО ОКНО ОТКРЫТЫМ.

2. Двойной клик на run-gateway.bat — откроется второе окно с самим
   шлюзом, и автоматически откроется браузер на http://localhost:8080/

3. В браузере увидишь два источника (Modbus и OPC UA) с живыми
   значениями, обновляющимися каждые ~0.7 сек. Вкладка "Config" —
   редактор конфигурации (можно добавлять/менять/удалять теги).

Чтобы остановить — закрой оба окна (или Ctrl+C в каждом).

ЗАПУСК С РЕАЛЬНЫМ ОБОРУДОВАНИЕМ
----------------------------------------------------------------------
1. Открой project.yaml в блокноте, пропиши реальные IP-адреса и теги
   своих устройств (примеры уже внутри файла).
2. Запусти run-gateway.bat (симулятор запускать не нужно).

Либо через командную строку (cmd.exe) из этой папки:
    PGW.Host.exe validate       — проверить конфиг, не запуская
    PGW.Host.exe export-map     — выгрузить карту регистров в CSV
    PGW.Host.exe simulate       — поднять тестовые серверы
    PGW.Host.exe                — обычный запуск (нужен project.yaml
                                   рядом с exe или переменная PGW_CONFIG)

ВОЗМОЖНЫЕ ПРЕДУПРЕЖДЕНИЯ WINDOWS
----------------------------------------------------------------------
- SmartScreen может показать "Windows защитила ваш компьютер" при
  первом запуске (файл не подписан цифровой подписью, это нормально
  для внутреннего инструмента) — нажми "Подробнее" -> "Выполнить
  в любом случае".
- Брандмауэр Windows может спросить разрешение на сетевой доступ —
  разреши, иначе панель и Modbus/OPC UA не будут слушать сеть.
- Если появится "не удалось найти совместимую среду выполнения" —
  значит .NET 8 всё-таки не установлен, см. ссылку в начале файла.

ДОСТУП С ДРУГОГО КОМПЬЮТЕРА В СЕТИ
----------------------------------------------------------------------
По умолчанию панель слушает только 127.0.0.1 (сам компьютер).
Чтобы открыть с другого устройства в сети, перед запуском gateway:
    set PGW_API_URL=http://0.0.0.0:8080
    PGW.Host.exe
Дальше на другом компьютере открой http://<IP-этого-компьютера>:8080/

ЕСЛИ НУЖЕН ПОЛНОСТЬЮ АВТОНОМНЫЙ EXE (БЕЗ .NET ВООБЩЕ)
----------------------------------------------------------------------
dotnet publish src/PGW.Host -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
(получится ~100 МБ, .NET runtime упакован внутрь exe)
