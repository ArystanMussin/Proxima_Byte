PGW — Protocol Gateway. Как запустить (Windows)
====================================================================

Это самодостаточная сборка: .NET runtime упакован прямо внутрь PGW.Host.exe.
Ничего отдельно ставить не нужно — ни .NET, ни что-либо ещё.

САМЫЙ ПРОСТОЙ СПОСОБ — ОДИН ДВОЙНОЙ КЛИК
----------------------------------------------------------------------
Просто дважды кликни на PGW.Host.exe.

При первом запуске это автоматически:
  - создаёт рабочий конфиг с тестовыми данными (если своего ещё нет);
  - поднимает встроенные тестовые Modbus TCP и OPC UA "приборы" с
    "дышащими" значениями — отдельного окна/процесса для них не нужно;
  - открывает браузер на панели управления (http://localhost:8420/).

В браузере увидишь источники данных с живыми значениями, обновляющимися
каждые ~0.7 сек. Вкладка "Config" — редактор конфигурации (можно
добавлять/менять/удалять источники и теги прямо в браузере).

Чтобы остановить — закрой окно PGW.Host.exe (или Ctrl+C в нём).
Если дважды кликнуть по exe, пока PGW уже запущен — просто откроется
браузер на уже работающей панели, второй экземпляр не запустится.

ПЕРЕХОД НА РЕАЛЬНОЕ ОБОРУДОВАНИЕ
----------------------------------------------------------------------
Тестовые источники, созданные на первом запуске — обычный конфиг,
который можно менять как угодно:
  - через вкладку "Config" в браузере (проще всего — не нужно знать
    формат файла), или
  - открой файл конфига в блокноте и пропиши реальные IP-адреса/порты/
    теги своих устройств:
        %ProgramData%\PGW\config\project.yaml
    (после правки — кнопка "Reload" в браузере или перезапусти exe).

Поддерживаемые протоколы: Modbus TCP/RTU, Меркурий (счётчики
электроэнергии), IEC 60870-5-104 (SCADA/телемеханика), DLMS/COSEM
(международный стандарт для счётчиков), OPC UA. Список источников и
все параметры — во вкладке "Config" или в самом project.yaml.

Командная строка (cmd.exe) из этой папки — для скриптов/автоматизации:
    PGW.Host.exe validate       — проверить конфиг, не запуская
    PGW.Host.exe export-map     — выгрузить карту регистров в CSV
    PGW.Host.exe simulate       — только тестовые серверы, без панели
    PGW.Host.exe                — обычный запуск (см. выше)
(любой запуск с аргументом не открывает браузер автоматически — это
поведение только для "чистого" двойного клика.)

ВОЗМОЖНЫЕ ПРЕДУПРЕЖДЕНИЯ WINDOWS
----------------------------------------------------------------------
- SmartScreen может показать "Windows защитила ваш компьютер" при
  первом запуске (файл не подписан цифровой подписью, это нормально
  для внутреннего инструмента) — нажми "Подробнее" -> "Выполнить
  в любом случае".
- Брандмауэр Windows может спросить разрешение на сетевой доступ —
  разреши, иначе панель и Modbus/OPC UA не будут слушать сеть.

ДОСТУП С ДРУГОГО КОМПЬЮТЕРА В СЕТИ
----------------------------------------------------------------------
По умолчанию панель слушает только 127.0.0.1 (сам компьютер).
Чтобы открыть с другого устройства в сети — запусти через
run-network-visible.bat вместо обычного двойного клика на exe, либо
вручную:
    set PGW_API_URL=http://0.0.0.0:8420
    PGW.Host.exe
Дальше на другом компьютере открой http://<IP-этого-компьютера>:8420/

ЕСЛИ ПОРТ 8420 ЗАНЯТ ДРУГОЙ ПРОГРАММОЙ (НЕ ДРУГИМ PGW)
----------------------------------------------------------------------
Задай любой свободный порт перед запуском:
    set PGW_API_URL=http://127.0.0.1:8888
    PGW.Host.exe
(поменяй 8888 на любой свободный порт; так же можно поменять порт
Modbus TCP сервера через project.yaml, раздел outputs -> port).
